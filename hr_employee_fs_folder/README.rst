Gives each employee a documents folder on an external file system
(configured with ``fs_storage``, e.g. a Google Drive Shared Drive served
over WebDAV), with a subfolder shared read-only with the employee:

::

   <id> - <name>/          HR only (contract, evaluations...)
     Shared/               HR and the employee (salary certificate, payslips...)

-  HR officers see the whole folder in the **HR Documents** tab of the
   employee.
-  Each employee sees only their own **Shared** folder, in *Employees >
   My Documents*, read only (download and preview).
-  The folders are created by a queue job when an employee is created,
   or with the action *Create Documents Folders* on existing employees.
   The folder is renamed when the employee is renamed.

The employees cannot read ``hr.employee`` (HR only), and every employee
can read every public profile (``hr.employee.public``) and every user
(``res.users``): the shared folder is therefore on its own model,
``hr.employee.shared.folder``, with a record rule restricting each
employee to their own folder (and HR officers to their companies).

Configuration
=============

1. Create a storage in *Settings > Technical > FS Storage* (for instance
   protocol ``webdav`` pointing to an ``rclone serve webdav`` of an HR
   Shared Drive, separate from other storages). Set *Check connection
   method* to *List File*.
2. In the storage, add both fields to the *Fields* linked to it: *HR
   Documents* (``hr.employee``) and *My Documents*
   (``hr.employee.shared.folder``). Leave *Models* empty.
3. Run the action *Create Documents Folders* on the existing employees.

On Google Drive, only HR is member of the Shared Drive (as
*Contributor*): the employees access their documents through Odoo only.
Do not move or rename the folders on the Drive: the link between an
employee and their folder is the folder path.
